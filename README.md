---

### Objetivo
Aprender na prática conceitos básicos de webdesign e desenvolvimento front-end, focando no aprendizado da linguagem JavaScript e na sua integração com HTML e CSS.

---

### O que foi aprendido
- **Sintaxe e operações básicas em JS:** uso de variáveis, funções, comandos e operadores.
- **Integração Front-end:** manipulação de elementos HTML através do JavaScript para interatividade.
- **Interação com usuário:** captura de inputs e exibição de respostas em tempo real.
